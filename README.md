# Azure AI Servicedesk – Interaktive Management-Präsentation (GitHub Pages)

Diese statische Single-Page-Webanwendung (`index.html`, `style.css`, `app.js`) visualisiert die Systemarchitektur, Datenflüsse, Sicherheits- & DSGVO-Regeln sowie die Wirtschaftlichkeits- und ROI-Analyse unseres **Azure AI Servicedesk-Projekts (Stufe 1 + Ausbaustufe 2 Voice/TTS)** ohne sichtbaren Programmier-Code.

## In 4 Schritten auf GitHub hochladen & GitHub Pages aktivieren

1. **Dateien im privaten Repository speichern:**
   Öffnen Sie Ihr privates GitHub-Repository (z. B. `https://github.com/mrvectorr/LLM`) im gewünschten Branch (`root` oder `main`) und laden Sie die drei Dateien `index.html`, `style.css` und `app.js` über **Add file → Upload files** (oder per `git push`) hoch.
2. **GitHub Pages Einstellungen öffnen:**
   Klicken Sie im Repository oben auf **Settings** und wählen Sie in der linken Seitenleiste unter *Code and automation* den Punkt **Pages**.
3. **Branch als Quelle festlegen:**
   Wählen Sie unter *Build and deployment → Source* die Option **Deploy from a branch**, stellen Sie darunter Ihren Branch (`root` oder `main`) sowie den Ordner **`/ (root)`** ein und klicken Sie auf **Save**.
4. **Live-URL für das Management aufrufen:**
   Nach ca. 30–60 Sekunden erscheint oben auf der Pages-Seite die fertige HTTPS-Adresse (z. B. `https://mrvectorr.github.io/LLM/`), über die das interaktive Architekturdiagramm und der ROI-Rechner direkt im Browser geöffnet werden können.
